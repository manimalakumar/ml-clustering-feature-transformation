# Clustering, Dimensionality Reduction, and Feature Transformation

Classical machine-learning experiments exploring clustering and feature transformation, with revenue prediction among the stated goals.

## Start here

- [ClusterDimRedFeatTransf.py](ClusterDimRedFeatTransf.py): inspect the experiment implementation.
- [data/](data/): inspect the included data files.
- [README.txt](README.txt): original setup notes and detailed historical environment record.

The original notes reference Google Analytics customer revenue data, an industrial energy dataset, and image data available through scikit-learn.

## Historical setup

The original environment used Python 3.6.2, scikit-learn 0.19.1, pandas 0.23.3, and NumPy 1.15.1 in Anaconda on Windows. The full package listing remains in [README.txt](README.txt).

For the Google Analytics workflow, the original instructions require obtaining `train.csv` from the [Kaggle competition data page](https://www.kaggle.com/c/ga-customer-revenue-prediction/data) and placing it under `data/GstoreCustomer/`. Dataset access is subject to the source's terms.

## Status and limitations

This is a learning project. The original code and environment notes are retained.
